# sidecar_pcb_hdr: one Sidecar board for every Atari, on a 2x25 bus header (draft)

The bare-module Sidecar board ([sidecar_pcb_xe](../sidecar_pcb_xe/)'s
layout, [sidecar_pcb_xl](../sidecar_pcb_xl/)'s circuit), with the
machine-specific edge connector replaced by a **2x25, 2.54 mm SMD socket**
(J1). A small adapter per machine plugs into it:

| Adapter | Machine | Its connector |
|---|---|---|
| [bus_adapter_pbi](../bus_adapter_pbi/) | 600XL, 800XL | the PBI card-edge socket (5530843-5), which the XL board carried |
| [bus_adapter_eci](../bus_adapter_eci/) | 130XE, 65XE | the cartridge + ECI fingers, which the XE board carried |

Why: one main board for both machine families (the XE board never got the
2026-11-18 re-spin; this one has it), no gold fingers or 50-way card-edge
socket on every spin of the expensive board, and insertion force and wear
go to a cheap part.

**Status: generated and autorouted, not reviewed.** A starting point.

## The bus header

`../tools/bus_header.py` holds the pinout; every generator imports it.
Header pin n is PBI pin n for every signal, so the PBI adapter is a straight
pass-through and this board keeps the XL board's net on each pin. The PBI's
three NC pins are GND on the header (12 grounds instead of 9). EXTDEC, CAS
and RAS pass through from the PBI and are open on the ECI adapter. Nothing
on this board uses them.

| Pin | Signal | Pin | Signal |
|---|---|---|---|
| 1 | GND | 2 | EXTSEL |
| 3 | A0 | 4 | A1 |
| 5 | A2 | 6 | A3 |
| 7 | A4 | 8 | A5 |
| 9 | A6 | 10 | GND |
| 11 | A7 | 12 | A8 |
| 13 | A9 | 14 | A10 |
| 15 | A11 | 16 | A12 |
| 17 | A13 | 18 | A14 |
| 19 | GND | 20 | A15 |
| 21 | D0 | 22 | D1 |
| 23 | D2 | 24 | D3 |
| 25 | D4 | 26 | D5 |
| 27 | D6 | 28 | D7 |
| 29 | GND | 30 | GND |
| 31 | PHI2 | 32 | GND |
| 33 | GND (PBI NC) | 34 | RESET |
| 35 | IRQ | 36 | READY |
| 37 | GND (PBI NC) | 38 | EXTDEC |
| 39 | GND (PBI NC) | 40 | REFRESH |
| 41 | CAS | 42 | GND |
| 43 | MPD | 44 | RAS |
| 45 | GND | 46 | READ |
| 47 | VCC50 | 48 | VCC50 |
| 49 | AUDIO | 50 | GND |

On this board, 47 is `VCC50_1` (to J6, as on the XL board) and 48 is
`VCC50_2` (unused). On the adapters, both are the Atari's 5 V.

## Mechanics

- **The stack.** The adapter stands in the Atari's connector. Its header
  (through-hole) is on its front face, and this board mates parallel to it,
  with J1 on this board's back. The modules face away from the Atari and the
  antennas point up, as on the XL board. `make_sidecar_hdr_pcb.py` turns
  J1 so that, seen from the front, socket pin n lies over header pin n on
  both adapters (it compares pad patterns and fails if none fits).
- **Position.** J1 is centred on a strip added below the XE board's body,
  so the board is 96 x 49 mm and the lower left corner is empty. The stack
  height (about 8.5 mm with a standard socket and header) and the fit
  behind each machine are unchecked.
- **Still to decide:**
  - **Keying.** Plain pins can be plugged in reversed or one row off, with
    5 V on the header. Options: a shrouded header on the adapters (the SMD
    socket must then fit inside the shroud), or a key pin (a header pin
    clipped and its socket hole plugged).
  - **Hold-downs.** The socket now carries the board's weight and every
    USB-C insertion at J9. Choose a socket part with pegs or board locks.
  - **Pitch.** 2.54 mm is cheap and sturdy. 2.0 mm would save about 12 mm
    of strip.

## Files

| File | |
|---|---|
| `sidecar_pcb_hdr.kicad_sch` | Generated by [`../tools/make_sidecar_hdr_schematic.py`](../tools/make_sidecar_hdr_schematic.py) from an XL schematic built with `--sidecar-usbc`: don't edit by hand |
| `sidecar_pcb_hdr.kicad_pcb` | Built by [`../tools/make_sidecar_hdr_pcb.py`](../tools/make_sidecar_hdr_pcb.py) from the XE board (all of its placement, J1 replaced, new outline), then autorouted |
| `sidecar_pcb_hdr.kicad_pro`, `.kicad_dru` | The project (copied from the XE board), and the XE board's J9 rule |

To rebuild (see [../AGENTS.md](../AGENTS.md)):

```
S=$(mktemp -d)
kicad-cli sch export netlist -o $S/sc.net hardware/espBusBangSidecar/espBusBangSidecar.kicad_sch
python3 hardware/tools/make_sidecar_xl_schematic.py hardware/espBusBangSidecar/espBusBangSidecar.kicad_sch \
    $S/sc.net hardware/symbols $S/xl-usbc.kicad_sch --sidecar-usbc
kicad-cli sch export netlist -o $S/xl-usbc.net $S/xl-usbc.kicad_sch
python3 hardware/tools/make_sidecar_hdr_schematic.py $S/xl-usbc.kicad_sch $S/xl-usbc.net \
    hardware/symbols hardware/sidecar_pcb_hdr/sidecar_pcb_hdr.kicad_sch
kicad-cli sch export netlist -o $S/hdr.net hardware/sidecar_pcb_hdr/sidecar_pcb_hdr.kicad_sch
(cd hardware/tools && /usr/bin/python3 make_sidecar_hdr_pcb.py ../sidecar_pcb_xe/sidecar_pcb_xe.kicad_pcb $S/hdr.net \
    ../bus_adapter_pbi/bus_adapter_pbi.kicad_pcb ../sidecar_pcb_hdr/sidecar_pcb_hdr.kicad_pcb)
hardware/tools/autoroute.sh hardware/sidecar_pcb_hdr/sidecar_pcb_hdr.kicad_pcb $S/hdr-routed.kicad_pcb 60
cp $S/hdr-routed.kicad_pcb hardware/sidecar_pcb_hdr/sidecar_pcb_hdr.kicad_pcb
```

The adapter boards come first (this script checks J1 against the PBI
adapter's header). `make_sidecar_hdr_pcb.py` imports helpers from
`make_bus_adapter_pcbs.py`, so run it from `hardware/tools`.
