# bus_adapter_pbi: 600XL/800XL PBI to the bus header (draft)

Plugs into the XL's PBI edge and carries the 2x25 bus header that
[sidecar_pcb_hdr](../sidecar_pcb_hdr/) mates with (pinout there and in
`../tools/bus_header.py`). It is a straight pass-through: header pin n is
PBI pin n. The PBI's NC pins (33, 37, 39) stay open on J1, and the header's
matching pins are GND.

| Ref | Part | |
|---|---|---|
| J1 | TE 5530843-5, 50-way 0.1" card-edge socket | the XL board's footprint. It is on F.Cu, but the connector is **soldered in from the back** (the face toward the Atari), as on the XL board. Don't flip it to B.Cu: that mirrors its holes |
| J2 | 2x25 2.54 mm pin header, vertical, through-hole | front face. Its pins sit in line with J1's (header pin n directly above socket pin n), so each net is a short vertical run |

Board 76 x 19 mm, two layers, autorouted, not reviewed.

Files: `bus_adapter_pbi.kicad_sch` is generated by
[`../tools/make_bus_adapters.py`](../tools/make_bus_adapters.py), and
`bus_adapter_pbi.kicad_pcb` is built by
[`../tools/make_bus_adapter_pcbs.py`](../tools/make_bus_adapter_pcbs.py)
and then autorouted. The ECI adapter comes from the same scripts.

```
S=$(mktemp -d)
kicad-cli sch export netlist -o $S/eci2pbi.net hardware/eci2Pbi/atari8EciToPbi.kicad_sch
python3 hardware/tools/make_bus_adapters.py hardware/symbols hardware/sidecar_pcb_xl/sidecar_pcb_xl.kicad_sch \
    hardware/eci2Pbi/atari8EciToPbi.kicad_sch $S/eci2pbi.net hardware
for b in pbi eci; do kicad-cli sch export netlist -o $S/$b.net hardware/bus_adapter_$b/bus_adapter_$b.kicad_sch; done
/usr/bin/python3 hardware/tools/make_bus_adapter_pcbs.py hardware/sidecar_pcb_xl/sidecar_pcb_xl.kicad_pcb \
    hardware/eci2Pbi/atari8EciToPbi.kicad_pcb $S/pbi.net $S/eci.net hardware
for b in pbi eci; do
    hardware/tools/autoroute.sh hardware/bus_adapter_$b/bus_adapter_$b.kicad_pcb $S/$b-routed.kicad_pcb 60
    cp $S/$b-routed.kicad_pcb hardware/bus_adapter_$b/bus_adapter_$b.kicad_pcb
done
```
