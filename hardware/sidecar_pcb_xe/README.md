# sidecar_pcb_xe: the Sidecar carrier with bare modules, XE (speculative)

[sidecar_pcb_xl](../sidecar_pcb_xl/) for the 130XE: the same circuit, but
J1 is the XE's **cartridge + ECI card edge** (the footprint of the
[eci2Pbi adapter](../eci2Pbi/)) instead of the PBI connector. The board
plugs straight into the XE, with no adapter.

**Status: autorouted, not reviewed.** Routed by
[`tools/autoroute.sh`](../tools/autoroute.sh): DRC shows no clearance errors
and nothing unconnected, and the schematic and board agree. Not checked by a
human yet, and its fit in the XE's cartridge opening isn't verified (the body
is exactly as wide as the two tabs, 80.6 mm, and stands 40 mm above them,
plus the antennas).

## J1: ECI ↔ PBI

Each card-edge pin carries the XL board's net for the PBI pin the eci2Pbi
adapter wires it to:

| Card edge | Net (PBI pin) | Card edge | Net (PBI pin) |
|---|---|---|---|
| 5, 4, 3, 2 | A0–A3 (3–6) | 10, 9, 8, L | D0–D3 (21–24) |
| C, D, E, F | A4–A7 (7–9, 11) | 6, 7, 11, M | D4–D7 (25–28) |
| H, J, P, N, K | A8–A12 (12–16) | R | READ (46) |
| D1, E1, F1 | A13–A15 (17, 18, 20) | S | PHI2 (31) |
| ECI 1-1 | EXTSEL (2) | ECI B1 | IRQ (35) |
| ECI 1-2 | RESET (34) | **ECI C1 (HALT)** | **READY (36)** |
| ECI 1-4 | MPD (43) | ECI 1-5 | AUDIO (49) |
| ECI 1-6 | REFRESH (40) | 13, ECI 1-7 | VCC50_1 (47) |
| B, ECI H1 | GND | | |

- **HALT:** the adapter joins ECI C1 (HALT) to PBI 36 (READY), so this board
  does too: the halt line works on the XE as on the XL boards.
- **Unused:** the PBI's EXTDEC, CAS, RAS and NCs have no ECI pin; nothing else
  on the board uses them. The cartridge pins S4, S5, RD4, RD5, CCTL and ECI
  D1XX and RESERVED are left open, as on the adapter.
- **5 V:** both card-edge 5 V pins go to `VCC50_1`, which J6 joins to the
  board rail, as on the XL board (fit J6 to run from the Atari; remove it when
  powering from J4/J5).

## Layout

The tabs run along the bottom edge: the ECI tab on the left, the cartridge
tab on the right (J1 is the adapter's footprint turned 180°; either face of
the board can be the front, see the adapter for which way it goes in). The
modules' antennas and the microSD slot point off the top edge; the
regulators U3 and U4 are on the back. Board 80.6 × 60 mm with the tabs.
`sidecar_pcb_xe.kicad_dru` lets J1's fingers run to the board edge.

DRC leftovers, as on the XL board: U1/U2 differ from the library (their
thermal vias widened to 0.3 mm, see the XL README), the modules' silkscreen
overhangs the top edge, two GND pads reach the pour through a single thermal spoke, and the
Atari8 footprint library isn't in the library table (J1's footprint is
embedded in the board).

## Files

| File | |
|---|---|
| `sidecar_pcb_xe.kicad_sch` | Generated by [`../tools/make_sidecar_xe_schematic.py`](../tools/make_sidecar_xe_schematic.py) from the XL schematic: don't edit by hand |
| `sidecar_pcb_xe.kicad_pcb` | Built by [`../tools/make_sidecar_xe_pcb.py`](../tools/make_sidecar_xe_pcb.py) (XL footprints, adapter's J1, XE placement), then autorouted |
| `sidecar_pcb_xe.kicad_pro`, `.kicad_dru` | Project and the card-edge DRC rule |

To rebuild after an XL change (see [../AGENTS.md](../AGENTS.md)):

```
S=$(mktemp -d)
kicad-cli sch export netlist -o $S/xl.net hardware/sidecar_pcb_xl/sidecar_pcb_xl.kicad_sch
kicad-cli sch export netlist -o $S/eci.net hardware/eci2Pbi/atari8EciToPbi.kicad_sch
python3 hardware/tools/make_sidecar_xe_schematic.py hardware/sidecar_pcb_xl/sidecar_pcb_xl.kicad_sch $S/xl.net \
    hardware/eci2Pbi/atari8EciToPbi.kicad_sch $S/eci.net hardware/sidecar_pcb_xe/sidecar_pcb_xe.kicad_sch
kicad-cli sch export netlist -o $S/xe.net hardware/sidecar_pcb_xe/sidecar_pcb_xe.kicad_sch
/usr/bin/python3 hardware/tools/make_sidecar_xe_pcb.py hardware/sidecar_pcb_xl/sidecar_pcb_xl.kicad_pcb \
    hardware/eci2Pbi/atari8EciToPbi.kicad_pcb $S/xe.net hardware/sidecar_pcb_xe/sidecar_pcb_xe.kicad_pcb
hardware/tools/autoroute.sh hardware/sidecar_pcb_xe/sidecar_pcb_xe.kicad_pcb $S/xe-routed.kicad_pcb 60
cp $S/xe-routed.kicad_pcb hardware/sidecar_pcb_xe/sidecar_pcb_xe.kicad_pcb
```
